# calcNitrogenFixationSymbiotic

calculates fixation from nitrogen-fixing crops

## Usage

``` r
calcNitrogenFixationSymbiotic(cellular = FALSE, irrigation = FALSE)
```

## Arguments

- cellular:

  cellular estimates optional

- irrigation:

  if TRUE, distinguishes irrigated and non-irrigated crops

## Value

List of magpie objects with results on country level, weight on country
level, unit and description.
